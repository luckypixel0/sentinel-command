# ◈ Overview

SentinelAI is an AI-powered Crime Intelligence Platform developed for **Datathon 2026**. It combines modern analytics, interactive mapping, predictive intelligence, investigation workflows, and AI-assisted insights into a unified operational dashboard for law enforcement.

The platform focuses on improving situational awareness, investigation efficiency, and strategic decision-making through intelligent data visualization and AI-powered assistance.

# ◈ Deployment

This project has been configured as a **standard Vite React application** and is compatible with **Zoho Catalyst Web Client Hosting**.

Deployment workflow:

1. Build the project
2. Generate the `dist` folder
3. Upload the build to Zoho Catalyst
4. Publish the application
