# SentinelAI

SentinelAI is an AI-powered Crime Intelligence and Investigation Platform designed for Karnataka State Police.

## Features

- AI Investigation Assistant
- Crime Analytics Dashboard
- Criminal Intelligence Network
- Crime Heatmap
- Predictive Operations Center
- Investigation Workspace
- AI-generated Investigation Reports
- Role-Based Access Control

## Tech Stack

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- shadcn/ui
- React Query
- Leaflet
- Recharts
- Framer Motion
